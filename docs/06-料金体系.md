## 3. 制作上の扱い

### 料金表は画像をそのまま貼らない → HTML テーブルで再構築する
理由：
1. 画像内テキストは**検索エンジンに読まれない**（目標KW「結婚相談所」「婚活」で不利）
2. スマホ幅で**文字が潰れて読めない**（ターゲットに50〜60代を含むため致命的）
3. 金額改定のたびに**画像の作り直しが必要**になる（先方が自分で更新できない）
4. スクリーンリーダーで読めない

> ただし配色・書体・あしらいの方向性は、この支給プラン表が
> **先方の既存ビジュアルアイデンティティ**なので尊重する（§5参照）。

### 連盟を横並びに出すだけでは選べない
IBJ／NNR／JBU は**連盟名であってプラン名ではない**。
閲覧者は「どれを選べばいいか」が判断できないため、料金表の手前に
**選び方ガイド**（どんな人にどの連盟が向くか）を置く構成とする。

想定：
- **IBJ** … 会員数最大・成婚数No.1。**とにかく出会いの母数を求める人**
- **NNR** … CONNECT-ship 経由で他11社の会員とつながる。**幅広く探したい人**
- **JBU** … 費用を抑えた設計。**まず無理なく始めたい人／再婚層**

※上記は制作側の仮置き。**先方の意図と一致するか要確認**。

### 複数加盟の説明が不足している
「2つ以上加盟の場合、登録料は高い加盟登録料のみ」とあるが、
**入会金と月会費が合算になるのか**が書かれていない。
閲覧者が最も気にする点であり、ここが曖昧だと問い合わせ前に離脱する。
→ 要確認のうえ、**具体的な組み合わせ例の総額**を提示する。

## 4. 特定商取引法への該当（重要）

結婚相手紹介サービスは、**期間が2か月を超え、かつ金額が5万円を超える**場合、
特定商取引法の「**特定継続的役務提供**」に該当する。

本件は IBJ で初期費用 ¥132,000 ＋ 月会費制のため、**該当が確定的**。
（NNR ¥55,000 / JBU ¥49,500 も、月会費を含む総額で5万円超となる）

さらに講座（3か月・¥110,000）も、本体サービスに付随する
**関連役務**として同様の規制対象になる可能性が高い。

### サイト上に必要となる記載
- **クーリング・オフ**（書面受領日から8日間）
- **中途解約**の可否と精算ルール
- 概要書面・契約書面の交付について

## 5. デザインへの影響

支給されたプラン表は **ローズピンク × ゴールド × 明朝体** のエレガント路線。
これは**先方が既に使っている既存のビジュアル**であり、ロゴのピンクとも整合する。

一方で先方の言語化されたトーンは
「派手よりも信頼と落ち着き」「煌びやかさはいらない」「あまり固くなく」。

→ **プラン表の路線をベースに彩度を落とす**のが、
　既存ツールとの一貫性とトーン指定を両立できる着地点。
　配色提案（02 §2-2）に**ローズ×ゴールド案**を追加して3案から選んでもらう。
