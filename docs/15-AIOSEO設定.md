## 6. サイトマップ

- 一般サイトマップ：**オン**（初期値）→ `https://loveliving-marriage.com/sitemap.xml`
- 含めるもの：投稿・固定ページ・カテゴリー（添付ファイル・タグ・投稿者・日付は外す）

## 7. 公開日（10/25）にやること

1. 設定 → 表示設定 →「検索エンジンがサイトをインデックスしないようにする」の**チェックを外す**
   （これがオンのあいだは、AIOSEO の設定に関係なく検索結果に出ません）
2. Google Search Console にプロパティ `https://loveliving-marriage.com/` を登録
   - 確認方法は「HTMLタグ」→ 表示されたコードを AIOSEO → 一般設定 → ウェブマスターツール → Google Search Console に貼る
3. Search Console → サイトマップ → `sitemap.xml` を送信
4. （任意）Google ビジネスプロフィールにもサイトURLを登録（地域検索で効きます）

## 8. 先方が記事を書くときのお願い（お知らせ・イベント）

- 記事の「**抜粋**」に1〜2文を書くと、検索結果とSNSの説明文になります。
- 「**アイキャッチ画像**」を入れると、一覧の写真とSNSシェア時の画像になります。
- AIOSEO の欄は触らなくてOK（タイトル・説明文は自動で入ります）。
