# 制作方針（ディレクション案）

## 0. 基本スタンス

この案件は「**要望が無い**」のではなく「**言語化できない**」タイプ。
先方自身が「丸投げと聞いていたのでどういうことを伝えたらいいのかわかりません」「この類は苦手な部類」と明言している。

したがって進め方は **オープンクエスチョン禁止・選択式で意思決定させる** に統一する。

| やってはいけない | やるべき |
|---|---|
| 「デザインの方向性は？」 | 「A案・B案どちらですか？」 |
| 「必要なページを教えてください」 | 「この7ページで確定でよいですか？ YES / 修正あり」 |
| 「料金を教えてください」 | 表の空欄を埋めてもらう（入会金◯円／月会費◯円…） |
| 「素材ください」 | 「9/22 までに未着のものは、こちらの代替案で確定します」 |

また先方は「**修正しながらでもできたら**」というスタンスなので、**修正回数と確定タイミングを先に握る**ことが必須。

### 「ストーリー的な流れ」の実装

```

→ 出会う（婚活の流れ・連盟ネットワーク）→ 暮らす（結婚後の保険・不動産まで）
```

この4ステップは、先方の「結婚相談所のこと／恋愛講座／結婚後も保険・不動産まで」という
説明の順番そのものなので、先方の頭の中の順序と一致する＝承認が通りやすい。

## 2. デザイン方針

### 2-1. 案01 と 案04 の統合方針

先方は 01（ストーリー＋上質ナチュラル）と 04（信頼・実績訴求型）を選んだが、この2案は方向性が逆行する。
そのまま混ぜると「上品だけど安っぽい」になる。**役割を分けて統合する。**

- **ベースは 01**（世界観・余白・書体・写真の使い方）
- **04 は「信頼の帯」として1ブロックだけ差し込む**
  - ファーストビュー直下に、連盟ロゴ（IBJ／JBU／NNR）＋数値実績を横一列の帯で配置
  - 数値は IBJ 公表値を**出典明記**で使用（自社実績の数値は根拠が取れるまで出さない）

これで「派手さは無いが、スクロールして最初に信頼が担保される」という先方の要望
（＝「ここなら頼めるかもという信頼が見える」）を満たす。

### 2-2. カラー方針 ★要承認

**問題：支給ロゴは「ビビッドなピンク × 黄緑」。**
これは「落ち着き・ちょっとした高級感・煌びやかさはいらない」というトーン指定と直接衝突する。
ロゴ色をそのままサイトカラーにすると、狙ったトーンにならない。

→ **ロゴの色相は継承し、彩度と明度を落として「上質」側に寄せる**方針を提案する。

**A案：ダスティモーヴ × セージグリーン（推奨）**
| 役割 | 色 | 備考 |
|---|---|---|
| 背景ベース | `#FBF8F5` | 温かみのあるオフホワイト |
| メイン | `#5F7A63` | セージグリーン（ロゴの緑を沈めた色） |
| アクセント | `#B98BAC` | ダスティモーヴ（ロゴのピンクを沈めた色） |
| テキスト | `#2E2A28` | 墨 |
| 罫線・補助 | `#DED5CC` | |

**B案：グレージュ × ディープグリーン**
| 役割 | 色 | 備考 |
|---|---|---|
| 背景ベース | `#F7F5F1` | |
| メイン | `#2F4A3C` | ディープグリーン（信頼・落ち着き寄り） |
| アクセント | `#C9A227` | 控えめなゴールド（高級感） |
| テキスト | `#22201E` | |

> **先方への出し方**：カラーパレットのみを2枚の画像で提示し「A / B どちらか」だけ選ばせる。
> 「どんな色がいいですか」とは絶対に聞かない。

### 2-3. タイポグラフィ
- 見出し：`Noto Serif JP`（明朝）— 「上質・落ち着き・ちょっとした高級感」の担保
- 本文：`Noto Sans JP`（ゴシック）— 「見やすい・読みやすい」の担保
- 本文サイズ 17px / 行間 1.9 — **ターゲットに50〜60代を含む**ため、一般的な16px/1.7より大きめに設定

### 2-4. あしらい
- 角丸は小さめ（4〜8px）、影は極薄。グラデーション・光沢は使わない（＝「煌びやかさはいらない」）
- アニメーションはフェードイン＋わずかな上方向移動のみ。視差効果・動画背景は使わない
- ロゴの「階段」モチーフを、セクション区切りの罫線あしらいとして低彩度で流用する

## 5. コンプライアンス方針 ★重要

| 論点 | 方針 |
|---|---|
| 「お客様の声」を「適当に」 | **創作不可**。実在の声（本人許諾済）がなければ、`よくある質問` ＋ `成婚までのモデルケース（※イメージと明記）` に差し替える |
| 成婚率・会員数の数値 | IBJ 公表値のみ、**出典・時点を明記**して使用。自社実績値は根拠資料が出るまで掲載しない |
| 「不動産仲介」 | 宅建業免許がなければ「仲介」と書けない。免許番号の確認がとれない場合は「提携先のご紹介」表現に統一する |
| 「保険アドバイス」 | 保険募集人登録がなければ、商品推奨にあたる表現を避け「一般的な情報提供」表現に統一する |
| 「業界公認 恋愛診断士／恋愛講師」 | **認定団体の正式名称**を確認のうえ併記。「業界公認」という曖昧表現は単体で使わない |
| 結婚相談所の料金表示 | 特定商取引法の「特定継続的役務提供」に該当する可能性（期間2ヶ月超・金額5万円超）。該当時は中途解約・概算清算の記載が必要 → **先方に確認**（IBJ の指導内容があるはず） |
| 個人情報 | 問い合わせフォーム設置につきプライバシーポリシー必須。事業者情報（商号・所在地・代表者名・連絡先）が未取得 |

> これらは「制作側の親切」ではなく**先方を守るための必須確認**として伝える。
> 特に不動産・保険の表現は、先方が資格を持っていない場合に法令違反リスクが生じる。

## 6. スコープ管理 ★最重要

契約：**5〜7ページ**。現行の要求は下記のとおり。

- 確定7ページ（§1）＝ **契約範囲内**
- プライバシーポリシー ＝ 範囲内（法務ページとして無償で作成）
- **取扱店申込ページ ＝ 8ページ目 ＝ 範囲外**

9/12 の発注から 9/15 までの3日間で、要望が**継続的に追加**されている（LINE／Instagram／LCIQ／取扱店）。
本人も「素材は何度かに分けて後送」「そのほかの材料も後送していきます」と明言。

**対応方針：**
1. 取扱店申込ページは「**外部LPへのリンク設置（追加費用なし）**」か「**サイト内新規ページ（別途見積）**」の二択で確認する。
2. **素材・原稿の支給締切日を明示**し、締切後の追加は次フェーズ扱いとする旨を合意する。
3. デザイン修正回数を明示（例：カンプ2回／実装後1回）。先方は「修正しながら」を前提にしているため、先に握らないと終わらない。
