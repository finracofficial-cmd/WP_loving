## 3. 実装をブロックしている中身の欠落

### A. 「創業の想い」の回答が抜けている ★
第2回の質問票で、先方の回答は下記の順で並んでいた。

```
Q16 住所 → Q17 電話 → Q18 写真 → Q19 料金 → Q20 キャンペーン
→ 【Q21 が無い】 → Q22 不動産・保険 → Q23 森香澄バナー → Q24 選び方
```

**Q21＝「創業の想い」が飛ばされており、未回答のまま**。
「A：入れてほしい」の回答も、設問（きっかけ／お客様にどうなってほしいか／大切にしていること）への
記入も無い。

→ `/about/` の中核セクションが**1文字も書けない**。
　創業2025年6月で実績が薄い本件では、ここが信頼の主軸になる予定だった。

### B. 入会資格・必要書類・面談の進め方が無い ★
`/flow/` を作るのに必要な情報が**一件も支給されていない**。

| 必要な情報 | 状態 |
|---|---|
| 入会できる年齢の範囲 | 無 |
| 男性・女性それぞれの入会条件（収入・就業状況など） | 無 |
| 入会時に必要な書類（独身証明書・住民票・収入証明・学歴証明 等） | 無 |
| 初回相談から入会までの手順と所要時間 | 無 |
| 入会後、最初のお見合いまでの目安期間 | 無 |
| お見合いの場所・形式（対面／オンライン） | 無 |
| 交際期間のルール（仮交際・真剣交際の期間） | 部分的（成婚料の定義に「交際期間は原則3ヶ月」の記載のみ） |

> 一般的なIBJ加盟相談所の標準で書くことは可能だが、
> **LOVE LIVING の実際の運用と違えば、誤った情報を掲載することになる**。
> → こちらで**たたき台を作り、○×で確認してもらう**のが最短（§5）。

### C. LCIQ が何なのかの説明が無い ★
講座の料金・時間・形式は揃っているが、**LCIQ そのものの説明材料が無い**。

| 必要な情報 | 状態 |
|---|---|
| LCIQ の正式名称（何の略か） | 無 |
| 何を測る指標なのか | 無（「恋愛指数」とのみ） |
| 診断の所要時間・設問数 | 無 |
| 診断結果で何がわかるのか | 無 |
| 誰が開発したものか（協会・企業名） | 無 |

支給済みプラン表の記載は下記のみ。
> 「LCIQとは、自己紹介術を学ぶ／自己分析で自分に気づく」
> 「LCIQの恋愛指数を高めていくことで自然と変わることができる」

→ これでは**診断ページの説明文が書けない**。
　LCIQ は本サイトの差別化の中核であり、ここが空だと「講座が3つ並んでいるだけ」になる。

### D. FAQ が 0 問 ★
`/faq/` は「よくあるご質問＋お客様の声」の構成で承認済み。
ところが、

- **FAQ は1問も支給されていない**
- お客様の声（1件）は **`/about/` へ移すことが確定**

→ **このページに載せるものが何も無い**。

> FAQ の原案はこちらで作れるが、**回答の中身**（入会資格・書類・支払方法・
> 休会の条件・オンライン対応の可否など）が §3-B と重複して不足しているため、
> **B が埋まらないと FAQ も書けない**。

### E. 支払方法が無い
料金は確定したが、**どう払うのかが不明**。

- 現金／銀行振込／クレジットカード／分割払いの可否
- 初期費用の支払タイミング（入会時一括か）
- 月会費の引き落とし方法・引き落とし日

→ 金額の隣に書く情報であり、**料金ページの完成度に直結する**。

### F. 公開日の具体的な日付
「10月下旬」で合意済みだが、**日付が確定していない**。
キャンペーン期間（3万円の期間＝公開日〜12月末）の起点が書けない。

### G. 連盟ロゴの使用可否
「IBJのメダルは使用不可。ほかの連盟の名前が載る場合は使えない」との連絡のみ。
**どのファイルが使えるのかが未確定**のため、トップの「信頼の帯」が組めない。

### H. 取扱店LPのURL
バナーを設置する方針で確定しているが、**リンク先のURLが未取得**。

### I. ドメイン・サーバー
第1回で取得・契約方法を案内したが、**完了の連絡を受けていない**。
**構築先が無いため、そもそもデプロイできない。**

## 4. 画像の調達方針（変更）

> **AI画像生成は本件の役務提供範囲外**。以下に限定する。

| 区分 | 対応 |
|---|---|
| 支給素材 | 代表写真4点／事務所写真5点／連盟ロゴ（可否確認中）／ロゴ（白背景JPG） |
| 支給素材の加工 | **明るさ・色調補正／トリミング／背景の切り抜き のみ**。服装変更等の生成的加工は行わない |
| 不足分 | **フリー素材（商用利用可・日本人モデル）で調達** |
| それでも足りないもの | **先方に共有を依頼する**（§5 の依頼リスト） |

### 先方に共有を依頼する画像
| # | 用途 | 内容 |
|---|---|---|
| 1 | ファーストビュー／各ページのヘッダー | **横位置（横長）の写真**。支給5点はすべて縦のため、横長が1点も無い |
| 2 | 代表の紹介セクション | 代表が**面談している様子**、または**話している様子**の写真（あれば） |
| 3 | 信頼の帯 | 他連盟と併記できる **IBJ／JBU／NNR のロゴ一式** |
| 4 | 資格の提示 | 恋愛ソムリエの**免許証**の写真（「免許証あり」との回答があったため） |

> 1・2 が無い場合はフリー素材で構成する。
> 3 が無いと信頼の帯が組めない。4 は無くても成立するが、あれば説得力が上がる。

## 4-2. 配色の進め方（確定）

> **デザインは1案のみ作る。承認前に複数案を作らない。**

- 弊社が **B案（`#2F4A3C` ディープグリーン × `#C1A86B` シャンパンゴールド）** を選定して組む
- ロゴのピンクは**差し色として少量**使い、ロゴとの繋がりを確保する
- **色は CSS カスタムプロパティ（カラー変数）で一元管理する。**
  完成後でも変数を差し替えれば全ページの配色が一括で変わるため、
  **事前に複数案を作る技術的な必要がない**
- 先方が色を変えたい場合は、実物を見てから調整する

```css
:root{
  --c-base:   #FBF9F6;  /* 背景 */
  --c-main:   #2F4A3C;  /* メイン */
  --c-accent: #C1A86B;  /* アクセント */
  --c-sub:    #B98BAC;  /* 差し色（ロゴのピンク由来） */
  --c-text:   #2E2A28;  /* 本文 */
  --c-line:   #DED5CC;  /* 罫線 */
}
```
