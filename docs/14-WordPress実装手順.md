# 14. WordPress 実装手順（本番サーバー反映）

確定したプレビュー（`preview/`）を、そのまま WordPress テーマにしたものが `wp-theme/loveliving/` です。
配布用 ZIP は `python3 tools/build_theme.py` で `dist/loveliving-theme.zip` に作られます。

---

## 1. 事前準備（5分）

1. 管理画面にログイン：`https://loveliving-marriage.com/wp-admin/`
   - エックスサーバーは初期設定で「海外からの管理画面アクセス」を制限しています。日本国内の回線からログインしてください。
2. **公開日まで検索エンジンに出さない設定**
   - 設定 → 表示設定 →「検索エンジンでの表示」の **「検索エンジンがサイトをインデックスしないようにする」にチェック** → 変更を保存
3. （任意）設定 → 一般 → 管理者メールアドレスが正しいか確認

## 2. テーマを入れる（3分）

1. 外観 → テーマ → **新規追加** → **テーマのアップロード**
2. `loveliving-theme.zip` を選んで **今すぐインストール** → **有効化**
3. 有効化すると、次の作業が自動で行われます（何度有効化しても二重にはなりません）

| 自動で行われること | 内容 |
|---|---|
| 固定ページの作成 | ホーム／LOVE LIVINGについて／婚活の流れ／恋愛診断・恋愛講座／料金プラン／お知らせ・イベント／よくあるご質問／無料相談・お問い合わせ／プライバシーポリシー／特定商取引法に基づく表記 |
| 表示設定 | トップページ＝「ホーム」、投稿ページ＝「お知らせ・イベント」 |
| パーマリンク | 投稿名（例：`/about/`、`/price/`） |
| カテゴリー | イベント告知（event-info）／イベントレポート（event-report）／お知らせ（info）。カテゴリーなしで投稿すると「お知らせ」 |
| 最初の記事 | 「Wedding Carnival in 銀座 を開催しました」（アイキャッチ画像つき） |
| 片付け | 初期の「Hello world!」「サンプルページ」をゴミ箱へ（削除ではないので戻せます） |
| その他 | 日付表示を `2026.10.25` 形式に、コメント受付をオフに |

4. サイトを表示して、全ページが確認用ページと同じ見た目になっているか確認

## 3. LOVE LIVING の設定（2分）

外観 → カスタマイズ → **LOVE LIVING の設定**

| 項目 | 設定する値 |
|---|---|
| お問い合わせの送信先メールアドレス | 先方の受信用アドレス（会社概要に載せているもの） |
| お支払い方法 | 初期値：現金／銀行振込／口座引き去り |
| お支払い方法の補足 | クレジット・Pay払いが始まったらここに1行（例：初期費用・成婚料は、クレジットカード・PayPayでもお支払いいただけます） |
| 月会費の口座振替日 | 27 |

→ 料金プラン・よくあるご質問・特定商取引法の表記の3か所に自動で反映されます。

## 4. お問い合わせフォームの動作確認（5分）

- プラグインは不要です（テーマに組み込み済み。迷惑送信対策として、隠し項目・送信時間チェック・ワンタイムキーを入れています）。
- 送信すると、①送信先アドレスに内容が届き、②お客様に自動返信メールが届きます。
- **自分のアドレスで1回テスト送信**し、次の2通が届くか確認してください。
  - 「【LOVE LIVING】お問い合わせがありました（○○ 様）」
  - 「【LOVE LIVING】お問い合わせを受け付けました」
- 届かないときは迷惑メールフォルダを確認してください（送信元は `wordpress@loveliving-marriage.com`）。それでも届かない場合は、エックスサーバーで `info@loveliving-marriage.com` を作り、SMTP 送信用プラグインを入れます。

## 5. 公開日（10/25）にやること

1. 設定 → 表示設定 →「検索エンジンがサイトをインデックスしないようにする」の**チェックを外す**
2. スマホ・PCで全ページを確認
3. （任意）Google Search Console にサイトを登録し、`https://loveliving-marriage.com/wp-sitemap.xml` を送信

## 6. 先方が自分で更新するところ（お知らせ・イベント）

1. 投稿 → **新規投稿**
2. タイトルを入力
3. 本文を書く。写真は「＋」→「画像」または「ギャラリー」（スマホから直接アップロード可）
4. 右側の設定で
   - **カテゴリー**：イベント告知／イベントレポート／お知らせ のどれかにチェック
   - **アイキャッチ画像**：一覧に出る写真（なくても表示は崩れません）
   - （任意）**抜粋**：一覧に出る短い説明文。空欄なら本文の最初が使われます
5. **公開**

- トップページには新しい順に最大3件、一覧ページには9件ずつ表示されます。
- 記事が0件のときは、トップのお知らせ欄ごと表示されません。

## 7. 固定ページの文章について

- 「ホーム」「LOVE LIVINGについて」などの固定ページの中身は**テーマで作られています**。管理画面の編集画面に文章を書いても表示されません（編集画面にもその旨の案内を出しています）。
- 文章の修正は `preview/` 側を直してから `python3 tools/build_theme.py` で ZIP を作り直し、
  外観 → テーマ → 新規追加 → アップロード →「**現在のものをアップロードしたもので置き換える**」で反映します。
- 新しく作った固定ページ（上の一覧にないスラッグ）は、管理画面で書いた本文がそのまま表示されます。

## 8. 補足

- Cocoon（クイックスタートで入ったテーマ）は使いません。有効化後は削除して構いませんが、予備として WordPress 標準テーマ（Twenty Twenty-Five など）は1つ残してください。
- セキュリティプラグイン「CloudSecure WP Security」はそのまま有効で問題ありません。
- 検証：この手順はローカルの WordPress 7.1.3（日本語版）で、テーマのインストール → 自動セットアップ → 全ページ表示（200）→ 404 → フォーム送信（通知・自動返信）→ 迷惑送信の破棄 → 設定変更の反映 → 再有効化で二重作成されないこと、まで確認済み。
